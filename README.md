# CollMan catalog

Public reference catalogs for the CollMan collection manager. Application source and personal collection data are not stored here.

[Download the latest catalog](https://github.com/AntoninoFulci/CollMan-catalog/releases/latest)

CollMan checks the latest release manifest at startup, verifies the download, and activates catalog updates on the next launch. The existing catalog remains available offline.

Stable update endpoint:

```
https://github.com/AntoninoFulci/CollMan-catalog/releases/latest/download/catalog-manifest.json
```

Release assets include the SQLite catalog, versioned update manifest, SHA-256 checksum and source attribution. Card text and related materials retain their original copyright; see each release's `CATALOG-NOTICE.md`.
